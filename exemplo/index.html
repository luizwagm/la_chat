Empresa Demo

Um site qualquer, que instalou o LA Chat com duas linhas.

Quem está usando

Entrar como Ana Entrar como Bruno Entrar como Carla

Como testar em tempo real

  • Abra esta página em duas janelas anônimas (ou dois navegadores).
  • Entre como Ana numa e como Bruno na outra.
  • Clique no botão 💬 no canto, vá em Pessoas e escolha a outra pessoa.
  • Escreva. A mensagem aparece do outro lado sem recarregar nada.

O que este site precisou fazer

const chat = require("./lachat")({
  url: "http://127.0.0.1:5197",
  segredo: process.env.CHAT_SEGREDO_PASSE,
  contexto: "empresa-demo",
  usuario: (req) => sessaoDe(req),   // ← o contrato: quem está logado?
});

const servidor = http.createServer((req, res) => {
  if (chat.rota(req, res)) return;   // ← linha 1
  // ... o resto do site
});

chat.conectarUpgrade(servidor);      // ← linha 2 (WebSocket)

Mais nada. O chat não conhece o banco deste site, não conhece o model de usuário dele e não grava nada aqui.

Teste de isolamento visual

Esta página define button { font-family: "Times New Roman" } e .btn { background: hotpink } com !important. O botão abaixo obedece. O chat, ao lado, não — porque vive dentro de um Shadow DOM.
